# 照片浏览器 v0.4.13 / Photo Browser v0.4.13

- 修复按拍摄时间排序后左右切换跳过照片的问题：预览补充照片信息时保持当前浏览顺序，拍摄时间批量读取完成后再统一排序。
- 补全媒体数量及文件操作相关的英文提示。
- 支持 Apple Silicon 和 Intel，最低 macOS 14；v0.4.12 可通过应用内检查更新升级。

- Fixes skipped photos when navigating by capture time. Preview metadata updates preserve the browsing order; capture dates are reordered together after background loading finishes.
- Completes English translations for media counts and file operations.
- Supports Apple Silicon and Intel on macOS 14 or later. Users of v0.4.12 can upgrade through Check for Updates.
