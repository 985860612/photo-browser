# 照片浏览器 v0.4.27

- 照片信息侧栏新增 AI 标题、描述、主体、场景、环境、元素、颜色、人物、空间、景别及特征，标签随侧栏宽度自动换行。
- 兼容已有识别结果中逗号、顿号、分号、竖线、换行和数组形式的标签，自动拆分并去重。例如“轮廓模糊，呈深色，有尾翼”显示为三个标签。
- 读取已有的本机或照片目录 V2 元数据，按照片目录及文件快照关联结果；支持刷新，并分别显示无结果、识别失败和读取错误。
- 多格式照片可在大图底部工具栏切换 RAW/HIF/JPG 等格式，全屏切换入口保持可用。
- 设置新增 AI 模型配置，默认 `qwen3.8-flash`，支持百炼 CSV 导入、钥匙串保存密钥及连接测试。“启用思考模式”默认关闭，每次请求明确传递开关状态。
- 照片侧栏支持生成、重新生成和取消。发送前将照片最长边缩至不超过 720 像素，保持比例；新结果保存在本机并保留历史，失败时保留旧结果。

已有 V2 识别结果可直接显示；配置模型后，点击生成会将缩小后的当前照片发送至所配置的服务。视频不显示 AI 照片信息，模型原始输出不在侧栏展示。原照片和批量识别记录不修改，新生成记录仅保存本机。AI 标签仍需人工复核。

# Photo Browser v0.4.27

- The inspector now shows existing AI titles, descriptions, subjects, scenes, environments, elements, colors, people, spaces, framing, and visual features. Tags wrap to fit the sidebar.
- Existing labels separated by commas, Chinese enumeration commas, semicolons, pipes, line breaks, or arrays are split and deduplicated for display.
- Reads existing local or photo-folder V2 metadata, matches results to the photo folder and file snapshot, and provides refresh and distinct missing-result, recognition-failure, and read-error states.
- Choose RAW/HIF/JPG and other paired image formats from the large-preview toolbar. Fullscreen format controls remain available.
- Added AI Model settings with `qwen3.8-flash` by default, Bailian CSV import, Keychain credentials, and a connection test. Thinking defaults to off and is explicitly sent with each request.
- Generate, regenerate, or cancel from the photo inspector. Photos are resized proportionally to a longest edge of at most 720 pixels before upload. New results are saved locally with history; failures preserve previous results.

Existing V2 recognition results display directly. Once a model is configured, clicking Generate sends the resized selected photo to that service. Videos omit this section, and the inspector does not show raw model output. Original photos and batch recognition records are preserved; newly generated records are stored only on this Mac. AI labels still need human review.
