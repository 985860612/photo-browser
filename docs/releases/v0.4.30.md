# 照片浏览器 v0.4.30

- 新增独立的 AI 分类浏览模式：跨目录浏览已有识别结果，按主体、场景、环境、元素等标签组合筛选，并搜索描述、标签、文件名或目录。
- 照片右键新增“查看相似图片”：本机提取 768 维图片向量，在当前范围内按向量距离查找相似画面。索引支持暂停、续建和失败重试，原有筛选保持不变；首次建立时显示进度与已覆盖范围。
- 使用本机 SQLite 索引、分页和缓存统计，已完成的浏览范围直接打开缓存；刷新可核对照片变化，不重新调用模型。
- 目录右键支持从 AI 相册排除／取消排除，覆盖全部子目录；照片列表、数量和标签统计同步更新，原片与已有 AI 信息保留。
- 顶部工具栏切换 AI 分类／目录浏览，保留左右侧栏开关并记住显示状态与宽度；分类标题整行可点击展开／收起，搜索框使用细焦点描边。
- AI 分类支持拍摄时间升降序、大图／全屏预览、回到原目录、Finder 定位、复制及单张重新生成；排序菜单沿用目录模式样式，右键菜单补全图标。
- 保留无常规扩展名照片的已有格式信息，同名 RAW/JPG 继续合并展示；AI 索引排除视频、PSD/PSB、回收目录及 NAS 快照。

# Photo Browser v0.4.30

- Added a separate AI Categories mode for browsing existing recognition results across folders, combining subject, scene, environment, element and other tags, and searching descriptions, tags, filenames or paths.
- Added Find Similar Photos to photo context menus. Local 768-dimensional image vectors rank visually similar photos within the current scope. Indexing supports pause, resume and retries without changing the original filters, with initial coverage and progress shown explicitly.
- A local SQLite index, cursor paging and cached counts keep browsing responsive. Completed scopes reopen from cache; Refresh checks source changes without invoking a model.
- Folder context menus can exclude or include entire subtrees in the AI album. Photo lists, counts and facets follow these rules while originals and existing AI information remain intact.
- Switch modes in the window toolbar. Both side panels have visibility controls with remembered widths and visibility. Entire category headings expand or collapse, and search uses a thin focus border.
- AI browsing supports capture-time ordering, large/fullscreen previews, Show in Folder, Finder, copying and single-photo regeneration. Sorting shares the folder browser's menu style, and context actions include icons.
- Existing format information preserves photos without conventional filename extensions, while matching RAW/JPEG variants remain grouped. AI indexing excludes videos, PSD/PSB, recycle folders and NAS snapshots.
