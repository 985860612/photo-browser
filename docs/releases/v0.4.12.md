# 照片浏览器 v0.4.12 / Photo Browser v0.4.12

- 新增自动检查更新与新版提示，支持立即安装重启、稍后提醒和跳过版本。
- 在“设置 → 软件更新”中可开启自动下载并在退出时安装，文件操作期间会等待完成后再重启。
- 更新包与更新源均校验 Ed25519 签名，支持 Apple Silicon 和 Intel，最低 macOS 14。
- v0.4.11 及更早版本请手动安装本版一次，之后即可使用应用内更新。

- Adds automatic update checks and prompts, with install and relaunch, remind later, and skip version actions.
- Settings → Software Update offers background downloads and installation on quit. Restart waits for ongoing file operations.
- Update archives and feeds use Ed25519 signatures. Supports Apple Silicon and Intel on macOS 14 or later.
- Users of v0.4.11 or earlier need to install this version manually once to enable in-app updates.
