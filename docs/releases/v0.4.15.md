# 照片浏览器 v0.4.15 / Photo Browser v0.4.15

- 自动识别照片 GPSMapDatum 中的 WGS-84、GCJ-02 和 BD-09 坐标系标记；右侧显示采用的坐标系和判断来源。
- 在「设置 → 照片坐标系」中选择未识别时优先使用的坐标系，默认 WGS-84。设置立即生效并保存，明确的照片标记优先。
- 修复国内地图打开照片位置时的坐标偏移，按来源坐标系转换，避免已是 GCJ-02 的照片被重复偏移。国内地图模式仍按系统地区判断。
- 旧元数据缓存会补读坐标系信息，不重新生成缩略图，也不修改原始照片。
- 支持 Apple Silicon 和 Intel，最低 macOS 14；v0.4.12 及以上版本可通过应用内检查更新升级。

- Recognizes WGS-84, GCJ-02, and BD-09 markers in photo GPSMapDatum metadata. The inspector shows the selected coordinate system and how it was determined.
- Adds Settings → Photo Coordinate System to select the fallback for unrecognized metadata, defaulting to WGS-84. Changes apply immediately and persist; recognized photo markers take priority.
- Fixes photo-location offsets on mainland maps by converting from the source coordinate system and avoiding double offsets for GCJ-02 photos. The system region still selects the assumed domestic Maps mode.
- Enriches older metadata caches with coordinate-system information without regenerating thumbnails or modifying original photos.
- Supports Apple Silicon and Intel on macOS 14 or later. Users of v0.4.12 or later can upgrade through Check for Updates.
