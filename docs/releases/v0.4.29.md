# 照片浏览器 v0.4.29

- 将“生成／重新生成”操作移至“AI 照片信息”标题右侧的星光图标，移除下方独立按钮。
- 没有识别结果时点击图标生成信息，已有结果时重新生成；悬停提示和辅助功能标签同步显示对应操作。
- 读取或生成期间禁用图标，生成时保留进度、取消入口和错误提示；失败时保留已有结果，切换照片会取消当前生成。

# Photo Browser v0.4.29

- Moved Generate / Regenerate to the sparkle icon beside the AI Photo Information heading and removed the separate button below.
- The icon generates information when no result exists and regenerates existing information. Its tooltip and accessibility label describe the current action.
- The icon is disabled while loading or generating. Progress, cancellation, and errors remain available; failures preserve existing results, and switching photos cancels generation.
