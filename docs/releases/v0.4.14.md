# 照片浏览器 v0.4.14 / Photo Browser v0.4.14

- 修复 NAS 相册切图时的长时间等待：JPEG 的 EXIF 信息读取与大图、缩略图使用一致的顺序缓冲读取方式，避免混合读取路径并发打开同一文件。
- 按拍摄时间排序时，日期补全复用原始 EXIF 缓存；已有缓存时，即使原图暂时离线也可补全日期。
- 支持 Apple Silicon 和 Intel，最低 macOS 14；v0.4.12 及以上版本可通过应用内检查更新升级。

- Fixes long pauses when switching photos in NAS albums. JPEG EXIF reads use the same sequential buffered reader as previews, avoiding mixed access paths opening the same file concurrently.
- Capture-time sorting reuses cached original EXIF metadata, allowing date backfill when an original is temporarily offline and its metadata is already cached.
- Supports Apple Silicon and Intel on macOS 14 or later. Users of v0.4.12 or later can upgrade through Check for Updates.
