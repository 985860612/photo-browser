# 照片浏览器 v0.4.25 / Photo Browser v0.4.25

## 中文

- 在“设置 → 浏览 → 照片预览”中新增“显示对焦点”开关，大图和全屏共用，更改立即生效并自动保存，默认关闭。预览工具栏不再显示该开关。
- 支持包含 AF 区域记录的 Canon EOS 照片，已实测 EOS 70D 的 CR2 和原始 JPG：红框表示已合焦，黄框表示已选择。
- 支持包含有效对焦位置及框大小的索尼照片，已实测 A7 IV 的 ARW 和原始 JPG：青框表示相机记录的位置，不将其标为已合焦。
- 对焦框随缩放、拖动和 EXIF 旋转对齐，兼容 HDR 预览；手动对焦、缺少有效记录及暂不支持的文件会明确提示。
- 开启时才读取当前照片的对焦信息，需要安装 ExifTool（`brew install exiftool`）。不会改动原片；记录的对焦区域不保证该区域一定清晰。

## English

- Added Settings → Browsing → Photo Preview → Show Focus Points. The setting applies immediately to large and fullscreen previews, defaults to off, and remembers your choice. The switch no longer takes up space in preview toolbars.
- Canon EOS images with AF area metadata show confirmed points in red and selected points in yellow, verified with EOS 70D CR2 and original JPEG files.
- Sony images with valid focus location and frame metadata show the recorded area in cyan, verified with A7 IV ARW and original JPEG files. Recorded location does not imply confirmed focus.
- Frames follow zoom, pan and EXIF orientation and remain visible in HDR preview. Manual focus, missing metadata and unsupported files have explicit messages.
- Metadata is read only for the current photo while enabled. Requires ExifTool (`brew install exiftool`). Originals are never changed; recorded focus areas do not guarantee sharpness.

## 验证 / Validation

358 preview/navigation checks passed, including real Canon and Sony files, all eight EXIF orientations, zoom/pan alignment, cancellation and stale responses, preference persistence, and focus overlays on real HDR images. Chinese and English packaged resources and HDR decoding checks passed.
